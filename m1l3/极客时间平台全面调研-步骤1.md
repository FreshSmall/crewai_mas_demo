# 极客时间平台全面调研 —— 步骤1：研究框架与信息源清单

> 本步骤对应报告大纲第二章"研究背景与方法论"，旨在明确调研背景与范围边界、建立经过验证的信息采集渠道，为后续各步骤提供统一的研究框架。

---

## 1. 调研背景与任务界定

### 1.0 调研背景

当前正值AI技术浪潮重塑IT职业技能需求的关键节点：大模型与AI应用开发的兴起，使一线工程师与技术管理者面临大规模的技能更新压力，IT职业教育与知识付费市场随之进入新一轮需求扩张期。在这一背景下，极客时间官网主标语已更新为"极客时间-学 AI ，用极客时间"[^1]，提示平台战略重心正向AI主题内容迁移。此时对极客时间进行系统性全景调研，既能看清单一平台的产品与商业逻辑，也有助于观察整个IT在线教育行业在AI时代的转型路径，因而具有明确的现实决策参考价值。

### 1.1 调研对象与范围界定

**极客时间（GeekTime）**：极客邦科技（Geekbang Technology）旗下的IT职业教育与知识服务平台，产品形态覆盖C端（个人学习者）与B端（企业版）两类市场。

### 1.2 调研维度（与大纲步骤一一对应）

| 维度 | 核心问题 | 对应步骤 |
|------|---------|---------|
| 公司基本面 | 谁在运营极客时间？资本与组织情况如何？ | 步骤2 |
| 产品与服务 | 平台卖什么？产品矩阵与功能体验如何？ | 步骤3 |
| 商业模式 | 靠什么赚钱？定价与市场定位如何？ | 步骤4 |
| 内容生态与口碑 | 内容质量与用户真实满意度如何？ | 步骤5 |
| 市场与竞争 | 在IT在线教育赛道中处于什么位势？ | 步骤6 |
| 趋势研判与综合评估 | AI浪潮与行业变化带来什么机会与威胁？如何整体判断？ | 步骤7 |
| 报告整合与交付 | 如何按大纲输出可溯源的完整报告？ | 步骤8 |

### 1.3 研究方法：多源三角验证

考虑到极客时间为非上市公司、缺乏公开财务数据、用户口碑分散等客观约束，本调研采用"**官方信息打底 + 第三方数据交叉印证 + 用户口碑多渠道采集 + 行业报告横向对标**"的多源三角验证方法：

1. **官方一手信源**：极客时间官网、极客邦科技官网、InfoQ中国、QCon/ArchSummit大会官网——用于确认公司背景、产品体系、业务版图；
2. **数据类信源**：七麦数据（App数据与iOS口碑）、易观千帆（用户规模）、天眼查/IT桔子（工商与融资信息）、艾瑞咨询（行业报告）；
3. **口碑类信源**：知乎（深度讨论）、黑猫投诉（投诉舆情）、应用商店评论；
4. **竞品信源**：掘金、CSDN学院、拉勾教育、网易云课堂、慕课网、51CTO学堂等竞品官网与定价页。

对无法直接确证的数据（如营收、市场份额），报告将明确标注**置信度**（高/中/低），不做无依据推断。

## 4. 数据记录规范

- **每条关键信息**须记录：信息内容、来源描述、原始URL、采集时间；
- **引用格式**：正文一律采用Markdown内联引用 `[来源描述](URL)`，附录A登记完整来源清单；引用描述文字应简短明确，URL统一采用完整`https://`格式；
- **置信度标注**：高（官方一手信息/多源一致）、中（单一第三方来源）、低（间接推断/传闻）；
- **数据冲突处理**：不同信源数据冲突时，优先采用官方信源，并记录差异与可能原因。

## 5. 数据置信度与局限性声明

依据上述多源三角验证方法与实际采集验证结果，本调研的数据基础存在以下五类局限，后续各步骤与最终报告将据此对数据置信度进行分级标注：

1. **财务数据缺失**：极客时间为非上市公司，营收、市场份额、课程销量、完课率等核心经营数据无公开披露渠道，相关内容只能依赖行业报告估算与间接指标推断，置信度定为"低"或"中"；
2. **官方渠道抓取受限**：极客时间官网、极客邦科技官网均为JS动态渲染，静态抓取仅能获取站点标语等有限信息，产品入口与定价详情需浏览器人工访问，存在信息滞后风险；
3. **第三方平台反爬拦截**：慕课网（空内容）、51CTO学堂（安全验证页）、黑猫投诉（拦截页）、IT桔子（反爬令牌）、36氪（安全检测）等站点无法直接抓取，竞品信源仅4/6完成内容验证，口碑类信源均需登录/人工采集，样本时效性与完整性受限；
4. **行业报告获取不确定**：艾瑞咨询报告子域名DNS解析失败、多鲸资本官网SSL证书错误，行研数据的获取与引用存在不确定性，引用前须二次核验；
5. **口碑偏差风险**：知乎、应用商店评论、投诉平台等口碑渠道存在水军、极端评价与幸存者偏差，采集时将多源交叉并甄别，单项口碑结论置信度原则上不超过"中"。

上述局限已在第4节记录规范中建立对应的置信度标注机制，后续步骤与最终报告将逐项执行。
